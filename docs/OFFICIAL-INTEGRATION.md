## Gates in order / Sıralı koşullar

1. **Environment / Ortam:** host GPU and digest-pinned Docker GPU test, separately, on *this* host.
2. **Authorized release / Yetkili sürüm:** operator-provided reviewed, matching worker/backend/Compose/env/TLS bundle; accessible pinned version+digest images; verified devnet genesis/runtime. No `latest`.
3. **Model identity / Model kimliği:** actual registry hash, exact checkpoint revision and independently remeasured bytes, allowlisted decode-policy hash and JSON preimage checked against finalized chain. Catalog slug alone is not a checkpoint hash. Check BF16/quantization policy and vLLM/KV/context/concurrency on the device.
4. **Identity and calibration / Kimlik ve kalibrasyon:** separate miner identity per physical host, operator authorization/sponsorship, actual inference plus TOPLOC capture, registered account, accepted current bonded calibration. Keep seed, signer, wallet, keystore and session keys local/off Git; never send to an assistant or CI. Multiple GPUs per host may affect aggregate calibration; do not pool host identities.
5. **Accepted work / Kabul edilmiş iş:** authenticated public HTTPS session endpoint with least privilege, real DA delivery and gateway admission, then *separately authorized* positive finalized receipt. Neither a healthy worker nor a live price-source catalog proves accepted paid work. Do not expose raw backend `8000` or worker `8645` on the Internet; terminate HTTPS through an approved authenticated proxy or tunnel where required.

**No installer here. / Burada kurucu yok.** Do not recreate private operator files, silently install drivers, open ports, download model weights, reset Docker volumes (`down -v`), request a mnemonic or run a coin miner. The [checklist](MINER-CHECKLIST.md) records each missing proof instead. Revalidate sources before a future independently authorized runtime integration; run no financial/chain operation on the user's behalf.
